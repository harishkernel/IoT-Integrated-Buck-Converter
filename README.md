## How to Set-up

### Upload Arduino Code
- Open `arduino/buck_monitor.ino`
- Select Arduino Uno
- Select correct COM port
- Upload
- Open Serial Monitor at 9600 baud

### Run GUI Dashboard
- Open `processing_display/buck_display.pde`
- Change COM port if required
- Run the sketch
- View live dashboard
